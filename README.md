**Trenkwalder** — building **TalentAI**, an LLM-based candidate screening service.

- **EU AI Act–aware product design:** Designed neutral, non-judgmental UI for AI-generated assessments — replaced a red/green traffic-light flag system with a four-tier attention scale (none / low / medium / high), triple-encoded via label, shape and tone for accessibility and fairness
- **Microsoft Graph integration:** Email integration delivered; building Outlook calendar integration (view availability, create interview events, handle candidate declines and reschedules) using app-only permissions
- **Release engineering:** Moved the team from a Gitflow-style model to **trunk-based development** with feature flags, tag-triggered deployments, immutable artifact promotion and a defined hotfix flow
- **Feature flag architecture:** Designed a two-tier **PostHog** flag setup — shared flags centralised, app-specific flags per project — evaluated via direct HTTP calls without an SDK
- **Serverless config management:** Strategies for propagating **AWS SSM Parameter Store** changes to Lambda (forced cold starts, EventBridge-driven invalidation, deploy-time baking)
- **Monorepo CI/CD:** Per-service tag conventions (e.g. `backend/v1.2.0`) and pipeline scoping
- **Qualina voice agent:** Building a real-time conversational voice agent on the **Gemini Live** audio API — designing guardrails to keep conversations on-scope and compliant, tool calling to connect the agent to backend actions, prompt engineering for consistent, natural dialogue, and tuning voice-activity detection to avoid self-interruption
